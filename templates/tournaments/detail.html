Two real faults fixed on the way through: SPOTS LEFT NEVER WORKED. It was {{ tournament.max_players|add:"-"|add:tournament.player_count }} and Django's `add` filter cannot subtract. It returns "" when both the integer and the concatenation paths fail, so every tournament this site has ever had showed a dash there, full ones included. It is a model property now, tested. THE SIDEBAR "STANDINGS" WERE NOT STANDINGS. It listed the first ten registrations in signup order and numbered them 1 to 10, so whoever entered first sat at the top of a box labelled Standings no matter how they had played. It uses compute_standings now, and only appears once play has begun. The export menu was a Bootstrap dropdown, which needed Bootstrap's JavaScript. Three links cost less than the framework that hides them. {% endcomment %} {% block content %}
