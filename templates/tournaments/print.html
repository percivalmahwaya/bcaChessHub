{% comment %} The tournament report, for browser Print then Save as PDF. DELIBERATELY SELF CONTAINED. It does not extend base.html and does not load bch.css, for the same reason the email templates do not: print is a different medium. This document gets saved, mailed, and opened on machines that will never reach this server, so its styling travels with it. The palette is still the design system's, typed out rather than referenced. THREE THINGS FIXED IN THE MIGRATION: 1. IT STILL SAID "CHESSHUB". The site was renamed to Bulawayo Chess Hub on 2026-09-13 and this file was missed, so the printed report handed to players, parents and sponsors carried the old name for four days. It is the one artefact of this system that leaves the building on paper. 2. THE TOP THREE PLACES PRINTED AS EMOJI MEDALS, replacing the rank number entirely. On the office laser printers these reports actually come off, and in most PDF font subsets, those glyphs fall back to empty boxes, so first, second and third place printed blank on the prize sheet. Plain numbers, the same fix already made on the ratings page and for the same reason. 3. IT IGNORED SECTIONS. See the view: a tournament split into Open, Ladies and Developmental printed one merged standings table and one crosstable mixing players who never met. That sheet is the prize list. {% endcomment %} {{ tournament.name }}, tournament report
